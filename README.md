# Gleap Vue 3 and vite-ssg Example

Vue 3 and vite-ssg example showing client-side Gleap SDK initialization in a rendered app for customer support and feedback. The initialization example is in `src/main.ts`.

[Integration documentation](https://docs.gleap.ai/documentation/javascript/README) · [Gleap](https://www.gleap.ai)

This project shows on how to use Gleap (client-side library) with vuejs vite-ssg (server side rendering).
